# AgitPOS

**무인 동호회 아지트 운영을 위한 POS 및 회원 관리 프로그램**입니다.

관리자가 상주하지 않는 공간에서 회원이 직접 이용권과 물품을 결제하고, 운영진이 회원 정보와 입금·이용 내역을 관리할 수 있도록 만든 Android 앱입니다.

## 주요 기능

- **회원 관리**: 닉네임·PIN 로그인, 잔액 관리, 별도 입금자명 등록, 운영진 설정
- **POS 결제**: 이용권·음료·물품 선택, 수량 변경, 회원 잔액 차감
- **입금 확인**: 카카오페이 및 카카오뱅크 문자 알림 분석, 회원 매칭, 미확인 입금 수동 연결
- **회원권 관리**: 주간·월간 회원권 적용 및 만료 확인, 운영진 출석 적립
- **관리자 기능**: 상품 등록·수정·정렬, 대리 결제, 회원별 거래 내역 및 일별·월별·상품별 통계

## 기술 구성

Kotlin · Android XML / Data Binding · ViewModel / LiveData · Hilt · Firebase Authentication / Realtime Database

## 프로젝트 구조

```text
app/src/main/
├─ java/ggack/agitpos/
│  ├─ ui/          # 로그인, 회원·관리자 화면, 어댑터와 다이얼로그
│  ├─ domain/      # 결제·입금 규칙, 회원권 계산, 알림 분석, 상품 정렬
│  ├─ data/        # Firebase 통신, 로그인 세션, 데이터 모델, 입금 대기 기록
│  ├─ service/     # 입금 알림 수신과 앱 재시작 지원
│  ├─ bindings/    # 화면 데이터 바인딩
│  └─ utils/       # 권한·날짜·초성 검색 등 공통 기능
└─ res/            # 화면 레이아웃, 내비게이션, 문자열과 이미지
app/src/test/      # 업무 규칙·데이터 보존 회귀 테스트
tools/             # 로컬 Firebase 에뮬레이터 테스트 도구
```

개인 운영 환경에 맞춰 개발한 프로젝트입니다. 알림 문구와 수신 앱에 따라 자동 입금 인식에 제한이 있습니다.

빌드 설정과 테스트 방법, 개선 내용은 [개발 문서](docs/development.md)에 정리했습니다.
